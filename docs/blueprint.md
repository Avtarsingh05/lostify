# **App Name**: Lostify

## Core Features:

- Lost Item Reporting: Users can submit detailed reports for items they've lost, including images, descriptions, last seen location, date, and category.
- Found Item Reporting with AI Assistance: Users can submit reports for found items, uploading images which an AI tool then analyzes to auto-suggest item details like name and key attributes, along with current location.
- Interactive Item Map: A dynamic map displaying the reported locations of lost and found items with distinct markers (red for lost, green for found) and interactive item detail views with navigation.
- Secure User Messaging: A private, WhatsApp-style chat system allowing direct communication between users interested in specific items to facilitate return or claims.
- Personal Item Dashboard: A central place for users to view and manage all their reported items (lost, found, claimed) across dedicated tabs with clear status indicators.
- Basic Auction Listings: A browseable section showcasing items potentially available for return reward or digital auction, with basic item details and countdown timers.
- Admin Overview Panel: A simplified administrative panel providing a high-level overview of app activity, including total lost/found items and basic management functionalities.

## Style Guidelines:

- Primary color: A vibrant Indigo (#4F46E5) with HSL values of H: 243, S: 79%, L: 58%, chosen for its professional yet innovative feel, conveying reliability.
- Background color (Light Mode): A crisp, near-white base (#F9FAFB) for a clean and spacious visual environment.
- Background color (Dark Mode): A deep charcoal (#111827) for an elegant, premium look that reduces eye strain.
- Accent color: A bold Orange (#F59E0B) with HSL values of H: 38, S: 90%, L: 50%, designated for alerts and indicating lost items, demanding attention.
- Secondary color: A refreshing Green (#22C55E) with HSL values of H: 147, S: 74%, L: 46%, used to signify success, confirmation, and found items.
- Card backgrounds: Pure White (#FFFFFF) with soft shadows for light mode, and a rich Dark Grey (#1F2937) for dark mode, enhancing depth.
- Gradient accents: Headers feature an Indigo-to-Purple gradient, while success actions incorporate a vibrant Green-to-Teal gradient for dynamic visual interest.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-inspired, and impactful appearance.
- Body font: 'Inter' (sans-serif) for excellent legibility and a clean, neutral feel across all text, ensuring readability in various contexts like chat and descriptions.
- Modern, consistent icon sets, preferably custom SVG icons or a robust library like Font Awesome or React Icons, emphasizing clarity and alignment with the app's premium aesthetic.
- Utilize 3D-style cards throughout the UI, featuring pronounced elevation, soft shadows, and rounded corners (16-24px radius) to create a sense of depth and a 'modern card style'.
- Implement consistent spacing (padding and margins) across all components and screens to ensure a balanced, professional, and easily scannable interface.
- Forms are structured using a card-based layout for clarity, and critical UI elements like snackbars are designed as rounded, floating, colored notifications.
- Incorporate subtle yet engaging animations such as page transitions (slide/fade), button press effects, card hover/scale transformations, and smooth loading indicators for AI-driven processes.
